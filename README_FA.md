# ربات تلگرام مدیریتی — نسخه شروع

این نسخه یک اسکلت اجرایی و امن برای پنل مدیریتی تلگرام است:
- دسترسی فقط برای شناسه‌های مدیر
- ثبت یادداشت/مورد برای دو بخش `console` و `pc`
- مشاهده آخرین موارد و گزارش خلاصه
- ذخیره محلی با SQLite

**این نسخه هنوز به API سایت myDGN وصل نیست و خرید بازیکن یا انتقال کوین را خودکار نمی‌کند.** چنین عملیاتی ممکن است با قوانین EA/FC مغایرت داشته باشد و ریسک محدودیت حساب ایجاد کند. پیش از هر اتصال عملیاتی، باید محدوده مجاز استفاده از API و روش مورد تأیید EA روشن شود.

## راه‌اندازی روی Windows / macOS / Linux

1. Python 3.11 یا جدیدتر نصب کنید.
2. فایل فشرده را استخراج کنید و وارد پوشه پروژه شوید.
3. محیط مجازی بسازید:

   Windows:
   ```powershell
   py -m venv .venv
   .venv\\Scripts\\activate
   ```

   macOS / Linux:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. وابستگی‌ها را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```
5. `.env.example` را به `.env` تغییر نام دهید.
6. از BotFather توکن ربات بگیرید و در `TELEGRAM_BOT_TOKEN` قرار دهید.
7. ربات را موقتاً اجرا کنید و دستور `/myid` را بزنید؛ شناسه عددی خود را در `ADMIN_IDS` قرار دهید. سپس ربات را متوقف و دوباره اجرا کنید.
8. اجرا:
   ```bash
   python -m bot.main
   ```

## دستورات
- `/start`
- `/myid`
- `/addnote console عنوان | توضیحات`
- `/addnote pc عنوان | توضیحات`
- `/orders`
- `/summary`

## امنیت
- توکن تلگرام را در چت ارسال نکنید.
- فایل `.env` را منتشر نکنید یا در Git قرار ندهید.
- برای استفاده دائمی، سرور VPS و پشتیبان‌گیری از دیتابیس لازم است.
